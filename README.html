Stock Monitor — 使用说明书

基于 Go 后端 + SQLite 的个人股票盯盘工具。支持 A 股（沪深）、港股的实时行情、K 线技术分析、持仓盈亏跟踪、价格预警、AI 智能荐股和策略分析。提供 Web 前端 + Flutter 移动端。

快速开始

1. 编译

go build -o bin/server ./cmd/server

2. 配置 .env

PORT=3000
JWT_SECRET=自定义密钥
ADMIN_PASSWORD=管理员密码
DEEPSEEK_API_KEY=sk-xxx    # 可选，启用 AI 功能

3. 启动

./bin/server

首次启动会生成管理员账号密码并打印在日志中。访问 http://localhost:3000

功能说明

自选股 + 实时行情

添加/删除自选股。港股 HK:0700、A 股 SH:600519、SZ:000001。实时行情通过 WebSocket 推送。

K 线图

  • 时间周期：5 分钟、日 K、周 K、月 K
  • 均线周期自适应，买卖信号标记，北京时间显示

技术分析

  • 8 项卖出信号 + 10 项买入信号，加权评分
  • 按交易所筛选、按信号/名称排序

AI 策略分析

  • 17 种策略：均线金叉、趋势跟踪、放量突破、缠论、波浪理论等
  • 综合分析：并行运行全部策略，聚合输出多空对比、共识分歧、1-10 评分、操作建议
  • 盘中 2 分钟缓存，盘后 24 小时缓存
  • Markdown 渲染，时间戳自动转北京时间

AI 荐股

输入行业关键词，DeepSeek 推荐相关股票。自动去重、四因子排序。结果缓存 30 分钟。

持仓管理 + 价格预警

记录持股、实时盈亏计算。涨破/跌破/涨跌幅预警，WebSocket 推送通知。

常见问题

Q: 行情数据要付费吗？
A: 不需要，全部使用免费公开数据接口。
Q: AI 功能需要什么？
A: 配置 DEEPSEEK_API_KEY，在 DeepSeek 平台注册获取。
Q: 数据会丢失吗？
A: 数据存储在 SQLite 中，正常关闭不会丢失。
