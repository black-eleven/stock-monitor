股票盯盘工具 — 使用说明书

一个基于浏览器 + Node.js 后端的个人股票盯盘工具。支持 A 股（沪深）、美股、港股的实时行情、K 线技术分析、持仓盈亏跟踪和价格预警。

快速开始

1. 安装

cd hk-stock-monitor
npm install

2. 获取行情密钥

去 https://qos.hk 用邮箱注册，获取 API Key。免费，无需付费。

3. 配置密钥

编辑项目根目录的 .env 文件：

QOS_KEY=这里填你的API Key
PORT=3000

4. 启动

npm start

终端输出：

Stock Monitor running at http://localhost:3000

5. 打开浏览器

访问 http://localhost:3000

功能说明

自选股

添加股票： 点击页面上方的 + 添加自选股 按钮，按提示输入股票代码和名称。

港股代码格式：HK:700（腾讯控股）、HK:9988（阿里巴巴）、HK:00005（汇丰控股）
A 股代码格式：SH:600519（贵州茅台）、SZ:000001（平安银行）
美股代码格式：US:AAPL（苹果）、US:TSLA（特斯拉）、US:NVDA（英伟达）

查看行情： 添加后股票会显示为标签卡片，点击即可查看实时价格、涨跌幅、今开、最高、最低、昨收、成交量和成交额。

删除股票： 选中股票后，点击详情区域下方的 删除自选 按钮。

K 线图

在自选股 Tab 或 K 线 Tab 中均可查看 K 线图。

  • 支持时间周期：1分、5分、15分、30分、1时、2时、4时、日K、周K、月K
  • 绿涨红跌（统一颜色惯例）
  • 叠加 MA5（黄）、MA20（蓝）、MA60（紫）均线及卖出信号标记
  • 从 K 线 Tab 进入可查看更大尺寸图表

卖出分析

基于日 K 线数据，对自选股逐一进行技术面卖出信号扫描，以分层加权方式给出卖出指数（百分制）。

评分机制： 满分 13 分，实际得分 / 13 × 100% = 卖出指数。

信号权重说明
RSI 顶背离2.5价格创新高，RSI 未创新高 — 最强领先信号
MACD 顶背离2.5价格创新高，DIF 未创新高 — 动能衰竭
MA5 死叉 MA202.0短期均线下穿中期均线，趋势反转
MACD 死叉2.0DIF 下穿 DEA，动量确认转弱
成交量死叉1.5下跌日放量 > 上涨日，资金出逃
收盘 < MA201.0价格处于中期均线下方
RSI 超买1.0RSI(14) > 70，短期过热
收盘 < MA600.5价格处于长期均线下方（与 MA20 相关，降权）

阈值解释：

卖出指数颜色含义
≥ 50%🔴 红强烈卖出信号，建议关注
25–49%🟡 黄偏弱，注意观察
< 25%🟢 绿暂无明确卖出信号

使用方式：

  • 综合概要栏显示所有自选股的平均卖出指数
  • 点击个股卡片查看 8 项指标触发详情，每项显示状态（正常/警告/危险）和具体数值
  • 切换到分析 Tab 时自动拉取最新日 K 数据并刷新

持仓管理

记录你的实际持仓，实时计算盈亏。

添加持仓： 点击 + 添加持仓，输入：

  • 股票代码（如 HK:700）
  • 股票名称
  • 持有股数
  • 买入均价
  • 买入日期（可选）

查看盈亏： 顶部汇总显示总投入、总市值、总盈亏和总盈亏率。每条持仓显示股数、成本价、现价、盈亏额和盈亏率。

删除持仓： 点击持仓行右侧的删除按钮。

价格预警

设定价格条件，达到时自动通知。

添加预警： 点击 + 添加预警，选择：

  • 涨破 — 价格涨过设定值时触发
  • 跌破 — 价格跌破设定值时触发
  • 涨跌幅达 % — 涨跌幅达到百分比时触发

管理规则： 列表中可切换启用/禁用，或删除规则。

触发通知： 预警触发时，页面右上角弹出 Toast 通知，触发记录会在下方列表中显示。同一规则 30 分钟内不会重复触发。

连接状态

页面右上角显示 WebSocket 连接状态：

  • 绿色 已连接 — 正常接收实时行情
  • 黄色 连接中... — 正在连接后端
  • 红色 已断开 — 连接中断，自动重连

数据存储

所有数据存储在 hk-stock-monitor/data/ 目录下的 JSON 文件中：

文件内容
watchlist.json自选股列表
alerts.json预警规则
holdings.json持仓记录
alert-logs.json预警触发日志（保留最近 200 条）

数据仅在本地存储，不上传任何服务器。

技术说明

  • 前端： 原生 HTML + CSS + JavaScript，无框架依赖
  • K 线图： TradingView Lightweight Charts（CDN 加载）
  • 后端： Node.js + Express
  • 实时通信： WebSocket（后端 ↔ QOS 行情源 + 后端 ↔ 浏览器）
  • 行情源： QOS Market API（免费开源）

端口

默认 3000，可通过 .env 文件修改。

常见问题

Q: 为什么看不到实时价格？
A: 检查右上角连接状态是否为绿色。如果是红色，检查后端是否运行、QOS Key 是否正确配置。
Q: 行情数据是延迟的？
A: QOS 免费版为实时行情推送，延迟通常在毫秒级。
Q: 休市时间有数据吗？
A: 休市期间显示上一交易日收盘价，标注为休市状态。
Q: 数据会丢失吗？
A: 数据存储在本地 JSON 文件中，正常关闭不会丢失。如果 JSON 文件损坏（如磁盘写入异常），后端会报错并抛出异常，不会静默清空数据。
